# مشروع إدارة مركز التدريب — ASP.NET Core

مشروع Web API كامل بلغة C# مبني بـ ASP.NET Core 8، مع قاعدة بيانات SQLite وتسجيل دخول حقيقي بـ JWT.
الواجهة (الموقع) موجودة في مجلد `wwwroot` وتتقدم من نفس السيرفر — يعني نشر واحد بس ولينك واحد.

## قبل ما تشغّليه

افتحي ملف `appsettings.json` وغيّري:

1. `Jwt:Key` — حطي نص عشوائي طويل (32 حرف على الأقل)، ده اللي بيؤمّن تسجيل الدخول.
2. `Admin:Username` و `Admin:Password` — دول بيانات دخولك كأدمن. بيتزرعوا في قاعدة البيانات **أول مرة بس** يشتغل فيها المشروع، فلو غيرتيهم بعد كده مش هيتغيروا إلا لو مسحتي ملف `trainingcenter.db` وشغلتي المشروع تاني.

## التشغيل على جهازك — عن طريق Visual Studio

1. تأكدي إن عندك Visual Studio 2022 (أي إصدار حتى Community المجاني) مع تحميل "ASP.NET and web development workload" وقت التثبيت.
2. فكي الـ zip، وافتحي ملف `TrainingCenter.sln` بالدبل كليك — هيفتح المشروع كامل في Visual Studio.
3. في أول مرة، Visual Studio هيسحب المكتبات (NuGet packages) تلقائيًا — محتاج اتصال إنترنت لمرة واحدة بس.
4. اضغطي **F5** (أو زرار التشغيل الأخضر فوق) — المشروع هيتبني ويفتح المتصفح تلقائيًا على الموقع.
5. سجلي دخول ببيانات الأدمن اللي حطيتيها في `appsettings.json`.

لو ظهرت أي أخطاء حمراء في نافذة "Error List" جوه Visual Studio قبل ما تشغلي، ابعتيهاليّ نصها زي ما هي وهنحلها.

## التشغيل من التيرمنال (بديل)

يحتاج تثبيت .NET 8 SDK من الموقع الرسمي لـ Microsoft.

```bash
dotnet restore
dotnet run
```

هيفتح على رابط زي `http://localhost:5000` — افتحيه في المتصفح وسجلي دخول ببيانات الأدمن اللي حطيتيها.

## النشر (عشان تاخدي لينك حقيقي)

المشروع فيه `Dockerfile` جاهز، يعني ينفع ينشر على أي استضافة بتدعم Docker. أسهل خيارين مجانيين:

### الخيار الأول: Render.com
1. اعملي حساب مجاني على render.com.
2. اضغطي "New" → "Web Service".
3. ارفعي المشروع على GitHub (أو اربطي مجلد المشروع مباشرة لو Render بيدعم رفع مباشر).
4. Render هيكتشف الـ Dockerfile تلقائيًا ويبنيه وينشره.
5. هتاخدي لينك زي `https://your-app.onrender.com`.

### الخيار الثاني: Azure App Service (الفئة المجانية F1)
1. اعملي حساب Azure مجاني.
2. اعملي "App Service" جديد، اختاري "Docker Container" كطريقة النشر، وأشيري لنفس المشروع.
3. هتاخدي لينك زي `https://your-app.azurewebsites.net`.

## ملاحظة مهمة عن قاعدة البيانات

المشروع بيستخدم SQLite (ملف واحد `trainingcenter.db`) عشان يكون أبسط شي للتشغيل. المشكلة إن بعض الاستضافات المجانية (خصوصًا اللي شغالة بـ Docker) بتمسح الملفات كل ما تعيدي النشر (redeploy)، يعني ممكن تفقدي البيانات. لو محتاجة البيانات تفضل محفوظة بشكل دائم مهما نشرتي، الحل إنك تستخدمي قاعدة بيانات سحابية حقيقية (زي PostgreSQL على Render نفسه، مجاني) بدل SQLite — لو وصلتي للمرحلة دي قوليلي وأعدّل الكود يشتغل عليها بدل SQLite.

## هيكل المشروع

```
TrainingCenterApi/
  Controllers/     ← نقاط الاتصال (API endpoints)
  Models/          ← جداول قاعدة البيانات
  Data/            ← الاتصال بقاعدة البيانات
  Services/        ← تشفير كلمة المرور وتوليد التوكن
  Dtos/            ← أشكال البيانات المتبادلة مع الواجهة
  wwwroot/          ← الموقع نفسه (index.html)
```
